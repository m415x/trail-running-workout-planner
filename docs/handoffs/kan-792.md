## Boundary implemented

- `getCompetitionCalendarAction({ planId, locale })` reads only the authorized Plan calendar. `planId` is a resource locator, not authority.
- `createAuthorizedCompetitionCalendarReader` composes real H2 EPT authentication (`requireAuthenticatedEptAction`), effective H3 active Team, real H4A `planning.manage` TEAM scope, Drizzle Plan → Sporting Group ownership and the existing `getCompetitionCalendar(planId)` repository.
- Anonymous/unlinked/invalid H2, unresolved/ambiguous/revoked Team, absent `planning.manage`, deleted Plan/Group and foreign Plan/Team deny before calendar read. No global Team fixture authorizes the reader.
- The preview's `competitionCalendarResult.ok === false` takes `notFound()`, **not** `[]`; an authorized Plan whose calendar has zero entries returns `ok: true, value: []`. No new generation algorithm, explanations, snapshots or persistence transport.
- CompetitionEntries remain Plan-scoped for Base and Variant, with existing date/distance compatibility derived at read time. Deleted entries are omitted by the repository. No modifications to global RaceEvent/RaceEdition/RaceCourse catalogue or existing lifecycle semantics.
