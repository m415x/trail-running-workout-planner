# KAN-380 — Safe physiology integration handoff

Status: closure work in progress on `kan-380-safe-physiology-coach-athlete-stats`.

## Delivered story contract

KAN-380 integrates the Epic 4 field-performance model into Coach and Athlete surfaces without promoting the 1000 m track test into unsupported physiology.

- Canonical 1000 m evidence, TestEvent/provenance/review lifecycle and accepted-evidence eligibility are preserved.
- Coach can register official evidence, review pending self-directed evidence and inspect factual history/evolution.
- Athlete can register evidence and inspect a compact safe performance projection.
- RunningReference uses accepted active evidence and deterministic pace/speed only.
- ExecutionGuidance keeps explicit quality percentages separate from Z1-Z5.
- Missing HR remains unknown; BPM is not generated from a zone or the 1000 m test.
- Trail/Hills/positive-grade presentation suppresses flat-reference quality pace/speed targets.
- New Trail/Hills sessions seed editable coach notes with `Priorizá el esfuerzo sobre el ritmo.`.
- Variable-terrain WorkoutCard also suppresses legacy group duration and its derived pace/speed so those values are not presented as individual athlete targets.

## Persistence and lifecycle audit

SQLite and Supabase schemas align on TestEvent, execution context, recorder role/user identity, review lifecycle, fixed 1000 m distance and elapsed-time evidence. Corrections are append-only replacements. Pending/rejected/invalidated evidence is excluded from analytical reference/evolution.

Application boundaries resolve athlete ownership before reads/mutations. Supabase migration/verifier coverage includes field-performance lifecycle columns, TestEvents and RLS. SQLite remains the current runtime repository for these actions; Supabase RLS is not claimed to protect SQLite calls.
