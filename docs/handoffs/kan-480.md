## KAN-460 acceptance audit

KAN-460 acceptance intent is satisfied without extending into H3+.

- A global monthly due-date exception is an explicit append-only fact scoped to one team/year/month. It replaces the base due-date candidate only for that period and does not mutate the permanent team policy.
- Global exceptions apply coherently to both future materialization and already-materialized charges. Reprojection is convergent.
- Reduction/scholarship is an explicit append-only revision scoped to one persisted monthly charge. It uses absolute minor units, allows total reduction to zero, supports explicit withdrawal and preserves the H1 base amount/currency.
- Individual extension is an explicit append-only revision scoped to one persisted monthly charge. Corrections and withdrawal retain history.
- Due-date precedence remains: team policy → global monthly exception → first-month activation clamp → `baseDueDate` → current individual extension → `effectiveDueDate`.
- A later global exception never deletes an individual extension. Projection uses the later base/extension date, while the extension remains auditable and can become effective again if the base date moves back.
- H2 introduces no implicit proration, payments, credits, balances, derived account state or additional charges.

These contracts are enforced at domain, persistence and integration boundaries and are represented in focused H2 contract/persistence tests.
