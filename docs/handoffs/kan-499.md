# KAN-499 — KAN-463 H5 closure handoff

## Story

KAN-463 — H5 Experiencia Coach/Athlete y bloqueo por deuda anterior.

## Delivered contract

H5 is a pure application/presentation projection over H4. No H5 debt/block state is persisted.

`blocked_for_prior_debt` is true if and only if at least one charge:

1. belongs to a civil month before the current civil month; and
2. is already classified by H4 as `overdue`.

Consequences:

- prior-month + H4 `pending` under a still-valid extension => not blocked;
- once the extension expires and H4 becomes `overdue` => blocked;
- current-month `overdue` => red signal, not blocked;
- relevant prior charge becoming `settled` => block disappears by recomputation.

The H5 projection accepts an explicit civil `asOfDate`; it does not read runtime timezone/clock inside the domain function.

## Athlete delivery

The mobile `/profile` route:

- reuses `getCurrentAthlete()` from the existing development identity path;
- loads Membership through `createAthleteMembershipPageLoader`;
- passes only `membership.debtExperience` into Athlete presentation;
- does not migrate the rest of the current Profile mock or introduce KAN-298 auth/session behavior.

`AthleteMembershipStatus` renders:

- pending yellow;
- overdue red;
- settled neutral/light-dark compatible;
- a specific prior-debt explanation only when `blockedForPriorDebt` is true;
- ES/EN copy.

## Coach delivery

The existing Coach athlete Membership accordion continues to own H1-H4 operations and account/history presentation.

`MembershipAccountState` now also consumes the same `membership.debtExperience` and shows the prior-debt blocking notice without recomputing due-date or debt rules.

## Currency boundary

H5 introduces no monetary aggregation.

- Existing H4 `balanceByCurrency` remains the account-balance authority.
- Unlike currencies are not added together.
- No FX rate, conversion or synthetic cross-currency total is introduced.
- Athlete H5 presentation shows each charge in its persisted currency.

Any future requirement to compare, aggregate or settle across currencies requires a separate explicit product/domain decision.

## Persistence and security boundary

KAN-463 adds no schema, table, column, migration, RLS policy or mutable H5 authority.

It also adds no session, role, permission, redirect-based authorization or access-control enforcement. The debt block is Membership application behavior and remains separate from KAN-298 identity/authentication/authorization.
