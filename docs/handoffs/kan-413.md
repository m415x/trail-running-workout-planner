## Delivered contract

- `GroupSessionPrescription.durationMin` is explicit coach-planned **group duration**, in minutes.
- Absence is `null`/unknown. An explicit planned duration must be finite and greater than zero; zero is not an absence sentinel.
- Planned group duration is distinct from realized duration and from any future athlete-specific duration estimate.
- Coach ES/EN copy names the field explicitly as planned group duration.
- Athlete ES/EN presentation uses the same group-planning semantics rather than “estimated time”.
- Trail/Hills keeps planned group duration visible but suppresses athlete-facing pace/speed derived from the group duration or flat-reference guidance.
- Realized-training capture does not copy planned group duration into realized duration. The authoritative plan-real boundary remains the persisted session link; no date/title/workout similarity inference was introduced.

## Seed defect discovered during walkthrough

The KAN-413 walkthrough exposed a separate KAN-426 seed-ownership regression: `db/seed.ts` composed `seedPlanningTemplatesAndSessions` and then created a second active S2 planning hierarchy in its legacy planning block. SessionForm correctly reported the resulting current-week microcycle as ambiguous.

KAN-454 added an isolated `base-seed` scenario that executes the real `db/seed.ts` entrypoint and rejects multiple active microcycles for one group/date. The duplicate modular S2 planning hierarchy was removed while the canonical richer S2 hierarchy remains owned by the legacy base-seed block. The modular fixture still owns its standalone session fixture.

A clean SQLite rebuild then showed only the intended current S2 and M1 plans plus the separate prior-week KAN-297 historical walkthrough plan. Creating a new S2 session no longer reports an ambiguous microcycle.
