- Catalog creation validates selection and snapshot and passes the same Drizzle transaction to CompetitionEntry creation and catalog link, so an error in link rolls back the Entry. Public action signatures/error/redirect contracts retained.
- `runAuthorizedCompetitionMutation` gates five writers; on DENY, mutation callback is not invoked. This is not a separate capability grant.
