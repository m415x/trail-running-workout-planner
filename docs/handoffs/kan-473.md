## KAN-504 delivered baseline

KAN-504 consolidated the Coach model without introducing new domain authorities.

Visible vocabulary:
- ES: Grupo deportivo, Subgrupo de planificación, Plan base, Variante.
- EN: Sporting group, Planning subgroup, Base plan, Variant.

Operational model:
```text
Athlete
  → AthleteGroup / Sporting group
  → PlanningCohort / Planning subgroup
  → GroupTrainingPlan base / variant
  → CompetitionEntry
```

Delivered boundaries:
- `assignAthleteToGroup` remains the canonical Athlete ↔ Sporting-group mutation authority.
- A real group change on civil date `D` atomically closes open previous-group PlanningCohortMemberships on `D-1`; same-group assignment is a no-op; future changes/history rewrites are rejected.
- Sporting-group detail is now a natural Coach entry point for add/transfer, but reuses the same canonical mutation authority.
- Cohort variant derivation now has a real transactional persistence boundary around `derivePlanningCohortVariant`.
- Variant persistence copies strategies/preferences, hierarchy, microcycle targets and explicitly selected CompetitionEntries with remapped IDs; selected race-catalog sidecars are remapped too.
- Sessions and GroupSessionPrescriptions are not copied and variants remain `draft` until an explicit later Coach action.
- Planning-subgroup detail exposes derivation/review, validates eligible direct Base plans from the same group, reviews title/competitions and shows Base-plan lineage after creation.
- RaceCourse detail exposes a read-only planning-impact projection based only on persisted `competition_entry_race_courses` links. No name/date/distance inference is permitted.
- One RaceCourse may relate to independent variants in different Sporting groups; this never creates a cross-group Planning subgroup.

Durable contracts:

- `docs/architecture/competitions/race-catalog-planning.md`
