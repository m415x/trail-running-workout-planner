# KAN-379 — Factual 1000 m test evolution handoff

Status: complete and integrated into `dev` via PR #12.

## Delivered behavior

KAN-379 adds a consumer-neutral factual evolution projection for canonical `1000m_track` evidence.

- Active observations are projected in deterministic chronological order.
- Invalidated observations remain durable evidence but are excluded from the active evolution; append-only replacements participate normally.
- Each point preserves evaluation id, performed date, protocol and observed elapsed time; pace and average speed are arithmetic derivations.
- Latest/previous elapsed time comparison reuses shared analytics primitives for absolute delta, relative delta and mathematical direction.
- Zero or one active observation yields a non-evaluable comparison with insufficient-data semantics; no zero/default trend is fabricated.
- A lower elapsed time produces mathematical `decreasing`; this is descriptive only and makes no physiological claim.
- The authorized application read resolves athlete ownership before querying evidence. Cross-team/out-of-scope athlete requests return `athlete_not_found` without evidence access.

## Persistence and security

No schema, migration, RLS policy or persisted derived metric was added. KAN-379 reuses canonical `field_performance_tests` evidence and the existing ownership boundary. Deltas/trends remain reconstructible analytics rather than parallel authority.

## Acceptance audit

- No active evidence produces an empty series without fabricated values.
- One active observation preserves factual history while comparison remains insufficient.
- Two or more active observations deterministically select latest/previous.
- Absolute and relative elapsed-time deltas use the shared analytics comparison contract.
- Lower elapsed time is represented as mathematical `decreasing`, not as physiological improvement.
- Equal elapsed times are stable.
- Invalidated evidence is excluded; active replacement evidence is eligible.
- Evaluation date/protocol/identity are preserved.
- Athlete ownership is resolved before evidence reads; unauthorized subjects do not trigger evidence access.
- Analytics is read-only and does not mutate Planning, Training Response or canonical field evidence.
