## Delivered behavior

- `lib/sessions/session-microcycle-resolution.ts` resolves the single applicable microcycle for a group/date using inclusive start/end dates; absence and overlap are explicit results, never an arbitrary selection.
- `lib/sessions/session-microcycle-form-reconciliation.ts` independently reconciles selected groups on session-date/group changes. SessionForm automatically supplies the unique microcycle ID and blocks invalid submissions with ES/EN feedback.
- `lib/sessions/session-microcycle-boundary.ts` and `session-microcycle-integration.ts` validate the entire set of group prescriptions; both create and edit actions enforce the same authoritative date/lineage boundary before persistence.
- Team-owned active groups and nondeleted plan/macrocycle/mesocycle/microcycle lineage are checked server-side. Multi-group prescriptions retain their independent microcycle association.
- Session template/workout behavior, manual/generated ownership, stable generation keys and modification audit are preserved. KAN-411 does not generate plans or sessions, resolve planning cohorts, or alter intensity or `durationMin`.
